## Shared window

- **The Inventory, Map, Social, Quests and Character windows can share one place on screen,** as the game's panels do.
  Turn it on in the Config tab's Client UI Override. Opening one, from the toolbar or anywhere else, shows it there and
  closes whichever was showing. Each window has its own checkbox, so some can share while others stay on their own.
- **Tabs at the top switch between them.** The windows that share also share one position, size, lock, Size and background.
- **Attach to toolbar** holds the shared window where the game shows its panels: right above the toolbar, as wide as it,
  and following the game's UI scale. When one of the game's own panels opens there, the shared window closes so you can
  see it.

## Hide the game's hotbar

- **Hide hotbar** (Client UI Override, and the Hotbars page) hides the game's shortcut bar while nothing is on it, for
  players who use the plugin's hotbars instead. The toolbar's buttons stay. The bar comes back as soon as something is
  put on it, or when the setting is turned off.

## Map

- **Names on the world map never overlap.** They're placed by priority, only where the whole name fits, and zooming in
  makes room for more. Set each kind's priority with the arrows in **Show...**.

## Selling, trading and salvaging

- **Salvage button.** The inventory windows have a **Salvage** button that lists the carried items your active loot
  profile says to salvage, asks first, then salvages them. It can also run `/salvage combine` afterwards.
- **Sort and Salvage come first** in their row, so a narrow window keeps them.
- **Drop a pack on a vendor** to put its sellable items on the sell list.
- **Mark items for sale,** and they go on any vendor's sell list as it opens.
- **Drop items into a trade** to add them to it.
- **Drop items on the Ust's salvage panel** to put them on it. A pack adds its salvageable items, one material at a time.

## Fixes

- **Tools from the inventory work on things in the world.** With a key, lockpick or kit picked up from the plugin's
  inventory, clicking a door, chest or anything else in the world now uses it there.
- **Pack tags go on the pack you ticked.** Changing a carried pack's tags in the Tags list could put them on another
  pack if anything was appraised in between, while the list kept showing them where you meant them. A pack tagged
  "Weapons, Armor" could end up on your salvage pack, and `/sort` would fill it with weapons. The plugin now names the
  pack by its id, on a server that supports it.
- **The Tags list shows the tags a pack really has.** A moment after a change it shows the pack's actual tags, not the
  ones it sent.
- **Clear all tags works on carried packs.** A cleared pack kept showing its old tags, and the next tick put them back.
  It now stays cleared.
