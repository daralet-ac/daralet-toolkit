## Fixes

- **Items dragged onto the game's bank window go in the bank.** Dragging an item from the plugin's inventory onto the game's bank window (with the plugin's **Bank window** off) used to drop it on the ground. Now it goes into the pack you let go on, or onto the items row into the pack that's open (the one framed in green), at the slot you let go on. The slot it'll go in shows the green ring while you hold it there. The same works for an open chest. If the game's stack bar is set to part of a stack, only that many go. A pack goes into the bank itself, since packs can't go inside packs.
- **Items dragged from the game's bank window go in your packs.** Dragging an item from the game's bank window onto the plugin's inventory showed a red cross and did nothing. It now goes into the pack or slot you let go on, and the same works for an open chest or corpse. If the game's stack bar is set to part of a stack, only that many go.
- **The right mouse button turns the camera with the game's UI hidden.** With **Hide game UI** on (F1 to start), right-dragging no longer turned the camera. The plugin now hides each part of the game's UI and leaves the world view alone.
- **You can type an amount when splitting a stack.** With the plugin's chat windows on, the number box beside the game's stack slider lost every key you typed. Now only the game's chat bar hands its typing to the plugin's chat box.
