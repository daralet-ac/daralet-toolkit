## New

- **Escape opens the game menu.** With the **Options** panel's Replace on, pressing Escape when there are no windows left for it to close opens the Options window at **Gameplay Options**, like the game's own menu. Press Escape again while that page is showing and it asks whether to exit the game. With the game's own Options panel, Escape works as before.
- **The Quest Tracker can grow left or up.** Tick **Right-aligned** or **Bottom-aligned** in the tracker's settings or right-click menu to keep its right or bottom edge in place as quests are added and removed. That way it stays tucked into a corner of the screen. Dragging and snapping work as before.

## Fixes

- **The Radar leaves off what the game's radar leaves off.** Invisible creatures, spawners, pets and town guards the server keeps off the radar showed on the plugin's Radar and on the Dungeon window's markers. Now they're hidden there too, as on the game's radar.
- **Enter starts chat right after login.** With the plugin's chat windows on, Enter did nothing after logging in until you'd clicked somewhere. Now it opens the chat box straight away.
