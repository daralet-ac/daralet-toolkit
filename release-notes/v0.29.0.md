## New

- **Tab icons.** The main window's tabs are now pictures instead of words, so they fit in a narrow window: Config a gear, World a globe, Character a person, Social people, Combat an axe, Inventory a backpack, Quests a quill, Market a coin purse, Arena crossed swords and Leaderboards a medal. Hover one for its name. The button at the left of the tabs lists them all by name.
- **Config sub tabs.** The Config tab is split into **General**, **Client UI Override** and **Chat**. Chat's settings, which had their own main tab, are now here.

## Changes

- **Looter moved.** The Loot tab is now the Inventory tab's **Looter** sub tab. Its Test sub tab is gone: Loot highlights and the item tooltips already show what your profile does with each item.
- **Shorter settings.** Settings pages take up much less room. Each floating window's controls are one row (Enabled, Only when needed, Locked, Reset position, and Size and Background as short sliders), numbers are short sliders beside their checkboxes, and explanations are in tooltips. This covers Chat, Fellowship, Vitals, Target, Combat Text, World, the game panels, Hide UI, the Toolkit button and Borderless window.
- **Client UI Override in rows.** Its switches are grouped by where each window opens from: **Toolbar**, **Indicator** and **Floating**, with the shared window's switches under a line.
- **Each window chooses for itself.** The Toolbar window's buttons open the plugin's window for each one you've switched on under Client UI Override, and the game's panel for the rest.
- **The Book window** now starts in a window of its own instead of in the shared window.

## Fixes

- After a lifestone recall (`/ls`), chat could fill with "You must be in the world to use @playerui." once a second until you relogged. The plugin now hides that line and waits a few seconds before asking the server again. (If you still get stuck and can't move after `/ls`, relogging fixes it; that part is a server issue still being looked into.)
